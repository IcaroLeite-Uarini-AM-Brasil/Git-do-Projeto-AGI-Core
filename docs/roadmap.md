# Roadmap

## Phase 1: Foundation
- Modular package structure.
- Memory, safety and MCTS baselines.
- Dashboard and distributed worker examples.

## Phase 2: Agent Composition
- Cognitive agent orchestration.
- Tool execution and evaluation benchmarks.
- More robust memory retrieval.

## Phase 3: RL and Multi-Agent Expansion
- Actor-Critic improvements.
- Multi-agent coordination and environment scaling.
- More advanced symbolic reasoning hooks.

## Phase 4: Real-world Deployment
- Dockerization, telemetry, and operator dashboards.
- Safety governance and human oversight.
- Experiment tracking and checkpointing.
